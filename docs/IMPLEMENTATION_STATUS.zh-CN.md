## 本轮托管原件同步

schema v11 新增按账号、容器、物理数据库、zone、namespace 隔离的文件缓存与持久任务。新托管操作使用 immutable wire v2：文件 token 和清单代替发送端绝对路径；接收端验证摘要、大小及槽位后生成独立本地资产与打开副本。普通 Finder 引用不因此读取或上传外部文件。旧 v1 outbox 的 ID、原始 JSON 和摘要不改写，迁移与旧分享文件接入使用新 ID 的因果后继补发。

发送端先确认原件再发布操作，打开副本的外部修改不会改变上传内容。接收端先持久保存操作与 cursor，缺文件时保留旧可用版本，原件全部验证后才事务应用。失败、重启、额度延期及同一 blob 多 revision 不丢任务或留下已完成的 pending。私有/共享均在成功与错误回执后重查账号配置及作用域；共享还核对权限代次。只读成员可以下载，失败草稿恢复明确留在本机。不同设备路径与资产 ID 不构成内容冲突。

单文件 64 MiB、单操作 64 文件/256 MiB、单次同步 512 MiB；CloudKit 使用每片不超过 32 MiB 的 CKAsset。增量拉取只取得文件元数据，按需下载并复制到独立 staging。系统返回的临时地址不会直接成为长久打开路径。当前账号的待上传、待下载和失败文件在设置中显示，可滚动查看并重试；状态读取失败不显示成“没有待处理文件”。

## 前轮重命名与图片旋转（c4d460a）

重命名直接以捕获的ID/revision读取一次编辑快照，保存仅更新用户标题。输入准备、失败保留、关闭确认、隐藏恢复和迟到回执沿用现有编辑器；旧账号或旧版本草稿不能自动重新授权后覆盖当前内容。原先无完成回调的重命名与旋转入口已移除。

图片只读预览不提前申请修改资格。旋转时先准备快照，再在后台应用EXIF方向并左转90度；仅修改预览的第一个图片对象，其他对象、用户标题和正文保留。普通单帧输出PNG，GIF保留原容器，GIF/APNG/TIFF保留全部帧，动画检查循环与时序，APNG保留原始延时分数。无法保留的多帧格式明确拒绝；当前上限1000帧/64 Mi总像素/512 MiB预算，8-bit RGBA转换的高位深/HDR保真仍待验。

失败保持原图并复用同一快照及转换结果重试；关闭或换上下文后的未提交转换失效。旋转的新OCR与图像在一次事务、一个revision内提交，避免后台OCR另增版本破坏连续旋转和撤销。Core核对识别文字与新图SHA256；即使识别文字与旧图相同，也保留新结果，Undo完整恢复原OCR。OCR失败允许保存图像修改；旧缓存仅在commit成功后清理，同版本或更新版本缓存保留，缓存失败不反转保存结果。Core在同一事务复用已验证原件，避免为了生成Undo再次读取完整附件，原先预算和权限检查保留。

## 正在关闭的差距

F03 已补上已知设备/未知来源筛选、字面子串索引和深页定位。旧记录不凭当前账号补写来源，备份不迁移本机安装身份。每次最多载入300条；普通过界空页回退，显式定位的目标失效则报错。后台刷新、旧排序回执与新的查询可能交错，必须用真实回执顺序的自动化回归检查选择不漂移。本轮 Mac 锁定，新增布局、全查询选择、跨页键盘操作与严格撤销的 CUA 实机验收暂未完成。

来源和设备菜单按数据库变化戳缓存，未变化的连续检索不重复全库聚合；同连接和其他连接写入均会失效。事务内不使用或发布缓存，回滚不会留下未提交结果。首次读取和写入后的重算仍有成本，不能用核心索引查询耗时代表整个App的响应。

`--validation --validation-search` 在独立临时目录生成908项合成记录，其中450项在“验收 · 深页”分组。两个唯一搜索词为`TARGET-DEEP-HISTORY`与`TARGET-DEEP-BOARD`，用于检索后Cmd-G定位；夹具含本机、合成远端与未知来源，不读取真实剪贴板。单独使用`--validation-search`不改变正常运行数据。

此前22:57–22:59版本已复核两行筛选布局、多板组合、板内单项键盘/鼠标排序与OCR预览。显式多板勾选在输入搜索词后保留；从单板浏览开始文字搜索时回到全局。排序只提交移动条目与插入锚点，不以当前分页替换整板；后台版本不匹配时拒绝并重新查询。本轮新增跨页多选、整批动作和并发失败恢复仍需实机验收。

手动排序视图中，普通拖动仅在板内调序，按住Option拖出原始内容；普通历史保留直接拖出。此交互有明确界面提示，仍需与Paste实机手势对标。卡片文字/图片的命中统一交由卡片处理；导出异步读取按一次鼠标手势绑定，松开或取消后不能迟发。

真实浏览器目标与辅助功能授权后的直接粘贴仍待验收。本轮尝试通过CUA打开本地`file://`网页夹具被URL安全策略拒绝，没有绕过或改用代理；以原生TextEdit空白临时文稿作为替代验证目标，不能替代浏览器输入框/富文本兼容结论。此前公开GitHub链接预览通过，也不能替代浏览器接收粘贴测试。
