## 本轮快捷键配置与注册生命周期

当前源码新增四组完整组合（面板、Stack、前一板、后一板）与 Quick Paste/纯文本两个单修饰键。固定应用内命令不开放重映射；配置拒绝重复、固定命令和数字输出冲突。纯文本选择驱动 Return、双击和 Quick Paste；恢复默认只重置六个快捷键字段，保留“始终纯文本”。

设置中的录制、修饰键变更会即时校验并探测系统注册，保存时再次校验。探测只临时注册新增组合并立即释放；保存先编码与注册新增组合，全部成功才替换映射并写偏好，失败保留现有可用注册及全部原偏好。交换面板与 Stack 组合复用已持有的句柄。启动分别报告两项注册状态；设置窗口为主窗口且正在录制时，可将 Carbon 已截获的本应用组合转交录制器，避免执行原动作。

显示与保留字符命令校验按当前键盘布局及真实修饰键解析，涵盖 Command 专属映射；事件路由优先使用实际字符，固定命令优先于自定义板切换。输入源变化刷新标签并结束录制，只停用不再合法的全局组合，保留其他组合，布局恢复后尝试重新注册。无法读取布局时只允许明确标注的 ANSI 标签回退，不能据此认可 Command 字符组合。旧 `shortcutPreset` 0/1/2 在内存中迁移；损坏、未知 schema 或当前布局下不合法的设置提示回退，原始偏好直到成功保存才被替换。

## 前轮跨页选择与批量动作（e55453c）

当前源码已接入完整查询的有序 `(id, revision)` 选择快照。列表 Cmd-A 与 Shift/Cmd 扩选不受 300 条可见窗口限制；分页保留选择，后台新增不自动加入，查询/会话变化使旧回执失效。任一选中项版本改变或被删除，输出与修改不能静默省略该项。

Core 同一读快照先校验全部引用及原始内容字节预算，再按冻结顺序读出。默认 512 MiB 是单次原始内容读取预算，不是进程 RSS 上限；超过预算、附件缺失或损坏均整批失败。删除、移板与完整板前后移在一个事务内校验全部版本及可写权限，失败不部分提交。纯本地移动和位置撤销不读取附件，同步关联项仍按既有协议逐项生成 outbox 内容。

编辑及批量移动/删除的撤销队列最多 10 个动作，删除/编辑原件累计最多 512 MiB，淘汰最旧动作以满足预算；单次删除超限时不执行。Core 生成的不透明凭据绑定资料库实例、原版本、相关板位置及私有/共享账号配置代次；连续编辑和编辑/移动交错撤销只用受信 receipt 衔接准确版本，不掩盖外部编辑或板内插入。删除恢复凭据成功消费一次，账号 A→B→A 也不恢复旧授权。备份恢复成功后清空撤销队列。已有同步 tombstone 的旧 ID 不允许撤销复活；历史恢复只保批次相对顺序，不还原原 rowid 位置。

该版本自动化用例覆盖完整查询/跨页选择、异步回执、双连接快照、只读与版本冲突、附件预算、事务回滚、连续撤销、配置切换及凭据重放。**提交 `e55453c`：2026-10-10 00:03 统一运行280项原生测试，0失败、1项跳过（本机FoundationModels不可用）；同轮原生release构建、App Intents元数据提取、本机ad-hoc签名及Node桥语法检查通过；[对应CI运行](https://github.com/Bestbbb/clipshelf/actions/runs/37956500803)通过。** 这些结果不包含本轮快捷键变更。上次桌面检查时 Mac 锁定，新增 UI 的真实 CUA/人工操作未完成；未取得辅助功能授权后的直接插入和真实云账号同步验收。

## 正在关闭的差距

F03 已补上已知设备/未知来源筛选、字面子串索引和深页定位。旧记录不凭当前账号补写来源，备份不迁移本机安装身份。每次最多载入300条；普通过界空页回退，显式定位的目标失效则报错。后台刷新、旧排序回执与新的查询可能交错，必须用真实回执顺序的自动化回归检查选择不漂移。本轮 Mac 锁定，新增布局、全查询选择、跨页键盘操作与严格撤销的 CUA 实机验收暂未完成。

来源和设备菜单按数据库变化戳缓存，未变化的连续检索不重复全库聚合；同连接和其他连接写入均会失效。事务内不使用或发布缓存，回滚不会留下未提交结果。首次读取和写入后的重算仍有成本，不能用核心索引查询耗时代表整个App的响应。

`--validation --validation-search` 在独立临时目录生成908项合成记录，其中450项在“验收 · 深页”分组。两个唯一搜索词为`TARGET-DEEP-HISTORY`与`TARGET-DEEP-BOARD`，用于检索后Cmd-G定位；夹具含本机、合成远端与未知来源，不读取真实剪贴板。单独使用`--validation-search`不改变正常运行数据。

此前22:57–22:59版本已复核两行筛选布局、多板组合、板内单项键盘/鼠标排序与OCR预览。显式多板勾选在输入搜索词后保留；从单板浏览开始文字搜索时回到全局。排序只提交移动条目与插入锚点，不以当前分页替换整板；后台版本不匹配时拒绝并重新查询。本轮新增跨页多选、整批动作和并发失败恢复仍需实机验收。

手动排序视图中，普通拖动仅在板内调序，按住Option拖出原始内容；普通历史保留直接拖出。此交互有明确界面提示，仍需与Paste实机手势对标。卡片文字/图片的命中统一交由卡片处理；导出异步读取按一次鼠标手势绑定，松开或取消后不能迟发。

真实浏览器目标与辅助功能授权后的直接粘贴仍待验收。本轮尝试通过CUA打开本地`file://`网页夹具被URL安全策略拒绝，没有绕过或改用代理；以原生TextEdit空白临时文稿作为替代验证目标，不能替代浏览器输入框/富文本兼容结论。此前公开GitHub链接预览通过，也不能替代浏览器接收粘贴测试。
