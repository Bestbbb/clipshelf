# ClipShelf 界面整理 · 2026-10-10

参考用户提供的 Paste 本机截图，调整现有 AppKit 面板。方向是简洁的 Mac 剪贴板工具：搜索、分组和内容预览有明确层次，保持系统字体、原生菜单和键盘操作。

## 现状与调整

| 改版前 | 本次调整 |
| --- | --- |
| 分组在左、搜索在右，视觉重心分散 | 搜索与分组集中在顶部中央；搜索默认只显示放大镜，点击、⌘F 或输入内容后展开 |
| 新建分组、筛选等按钮常驻 | 新建分组用加号；完整筛选可从更多菜单打开，搜索展开时也有筛选入口 |
| 分组按钮都呈现厚重的胶囊背景 | 只有当前分组显示轻量圆角底色，其他分组以文字和彩色圆点呈现 |
| 类型与时间挤在同一行，来源图标较小 | 卡片顶部拆为类型、时间两行，来源图标放大；部分已知来源采用稳定的来源色，其他按内容类型区分 |
| 内容区底部重复显示来源 | 文本与链接显示字符数，图片和文件显示内容描述；来源仍可通过图标、悬停和辅助功能读取 |
| 底部同时显示记录状态、结果数和整段快捷键说明 | 正常记录状态移到结果数的悬停说明；保留粘贴目标、分页、加载失败和其他操作反馈 |

## 保留的行为

单击卡片粘贴、搜索后回车进入结果、多选、拖出内容、分组拖动排序、快捷键、完整筛选与编辑功能均沿用现有实现。不会复制 Paste 的订阅提示、锁定遮罩或营销卡片。

没有辅助功能权限、记录暂停、读取失败或其他错误时，仍显示状态。搜索展开不清除已输入的文字；输入法组合期间不提交筛选查询。
